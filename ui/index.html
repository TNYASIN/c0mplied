HerEvidence is an AI helper that reads public clinical-trial records and looks for gaps that affect women: are women included, were results reported separately for women and men, and do the rules keep women out? It double-checks its own work and stops itself if it stops being reliable. With Synthetic data everything is made up for practice; choose Real to audit live ClinicalTrials.gov records.

iHow do I read the gap map?

Each row is a health condition. A higher gap score means women are less well covered in its trials, so it deserves a closer look first.

Example: if women are 26% of trial participants but 45% of patients, the PPR is about 0.58. Below 0.8 is usually read as under-representation. A gap is a question to follow up, never proof that something is wrong.

Glossary: words explained simply

No background needed
Clinical trial
A research study with people, used to test whether a treatment is safe and works.
Registry record
The public summary page of a trial. It may not contain everything in the full paper.
Agent / auditor
The AI program that reads trial records by itself and notes what it finds.
Supervisor
A watchdog that stops the agent if it makes too many mistakes, repeats itself, gets stuck or overspends.
Halt
When the supervisor stops a run. This is the safety system working. Even an unexpected error stops the run cleanly, with a report.
Set aside (quarantine)
Results held back because they came from a stretch of work that could not be trusted.
Quote check
Every claim must quote the record. If the quote isn’t really there, the claim is rejected.
Independent recheck
A few answers are asked again separately. If the two answers disagree, it counts as an error.
Loop detector
Notices the same step repeated and skips it, so the agent doesn’t go in circles.
Stuck detector
Stops the run if several rounds in a row make no progress.
PPR
Participation-to-prevalence ratio. The share of women in trials divided by the share of women among patients. Below 0.8 usually means under-representation.
No result by sex
The record doesn’t show results separately for women and men. It does not prove the analysis wasn’t done.
Blanket exclusion
A rule that excludes all women who could become pregnant outright. It is flagged for a person to review, not judged: some exclusions have safety reasons.
Gap score
0 to 100 priority score. Higher means a bigger gap. It mixes the PPR shortfall, missing results by sex and blanket exclusions.
Token
A small piece of text (about ¾ of a word). AI usage and cost are counted in tokens.
LLM call
One request to the AI language model.
Synthetic data
Made-up records for practice. Never cite them as research.
Draft request
A message to a trial team asking for missing information. It is only sent if a person approves it.
Handoff report
The note left at the end of a run explaining what happened and what to do next.
Gold set
A small set of studies with known correct labels, used as an answer key to measure accuracy. Ours is so far labelled by one AI reviewer, not yet checked by a person.
