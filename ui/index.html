LLM, with evidence

The model only judges eligibility wording and sex-stratified results. Every claim must quote the record, and code checks the quote exists.

Supervisor

Watches error rates, loops, progress and spend. On a halt it sets aside everything since the last clean batch and writes a handoff report.

Chance its error rate is above 10%
Quote checkIndependent recheckHalt line
Quote check– Every claim must quote the record. A quote that isn't in the source counts as an error, and the claim is rejected.
Independent recheck– A few answers per batch are asked again separately. Disagreement counts as an error.
Loop detector– The same call repeated three times skips that trial; too many skipped trials stops the run.
Stuck detector– Stops when several batches in a row resolve nothing.
Budget– Token, call, cost and time caps are checked before every model call.

PPR = share of women in trials ÷ share of women among patients; below 0.8 is usually read as under-representation. "No result by sex" means not found in the registry record, not that the analysis wasn't done. Gap score (0–100) weights PPR shortfall 50, no result by sex 30, blanket exclusion 20.
